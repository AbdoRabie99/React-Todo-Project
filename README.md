# React Todo List 📝

A simple and responsive Todo List application built with React. It helps users manage their daily tasks, track completed work, and keep their tasks saved even after refreshing the page.


🚀 **Live Demo:** [Try the App](https://react-todo-project-rho.vercel.app/)

A simple and responsive Todo List application built with React. It helps users manage their daily tasks, track completed work, and keep their tasks saved even after refreshing the page.
## ✨ Features

- ➕ Add new tasks.
- ✅ Mark tasks as completed with a strikethrough effect.
- 📋 Filter tasks to view completed and pending tasks separately.
- 💾 Save tasks in LocalStorage to persist data after refreshing the page.
- 🔔 Toast notifications for user feedback.

## 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- LocalStorage
- Vite

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/AbdoRabie99/React-Todo-Project.git
```

### 2. Navigate to the project folder

```bash
cd React-Todo-Project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
